Works with your AI

Your AI can read today's rainbow for you. It shows the live price against the long trend line. It names today's band and its price range. It counts the past days that sat in this band.

Connect this site to Claude, Cursor, or any other MCP client. It is free, and it takes about a minute.

1. Copy the server address

https://mcp.thebitcoinrainbow.com/mcp

2. Add it to your AI

Claude Code — one command 
claude mcp add --transport http bitcoin-rainbow https://mcp.thebitcoinrainbow.com/mcp
Claude Desktop or Cursor — paste into the MCP settings 
{
  "mcpServers": {
    "bitcoin-rainbow": {
      "url": "https://mcp.thebitcoinrainbow.com/mcp"
    }
  }
}

3. Ask your AI: “Where does bitcoin sit on the rainbow today?”
